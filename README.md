# Manual do Usuário: Pesquisa de Preços Lite

Este repositório contém a documentação pública do sistema Pesquisa de Preços Lite do Compras.gov.br.

## Estrutura do Projeto

- `mkdocs.yml`: Arquivo de configuração do MkDocs.
- `.readthedocs.yaml`: Arquivo de configuração para build no Read the Docs.
- `docs/`: Pasta com o conteúdo fonte da documentação em Markdown.
  - `index.md`: Página inicial da documentação.
  - `manual-completo.md`: Versão unificada para visualização completa e impressão.
  - `Imagens/`: Diretório contendo as capturas de tela e ilustrações.
  - `css/` e `js/`: Arquivos para estilização e comportamentos customizados.
